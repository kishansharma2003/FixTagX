IOI Validation
Determine the quantity eligible to be routed and advertised.
Min Notional Min ADV Max Notional Max ADV Valid IOI IOI Send QTY
Validation A: Order QTY must be greater than both Min Notional QTY and Min ADV QTY.
Validation B: If Valid IOI is TRUE, IOI Send QTY = MIN(Order QTY, Max Notional QTY, Max ADV QTY).
Important: If initial IOI validation fails, no IOI can be sent, so IOI Send QTY is shown as -.
